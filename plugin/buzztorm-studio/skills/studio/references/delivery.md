# Delivery package

Every approved version is delivered as files (with SendUserFile) plus `post.md`, also shown in the chat in a code block so it can be copied. Respect the Options on the review card: anything switched off is left out.

## File names
```
<brand>_<content>_<title>_v<N>_<size>.<ext>
```
Lowercase; hyphens inside a part, underscores between parts; size as `9x16`, `4x5`, `1x1`, `16x9`; slides and frames end in `_01`, `_02`…
Examples: `buzztorm_reel_daily-posting_v2_9x16.mp4` · `buzztorm_carousel_daily-posting_v1_4x5_03.png` · `buzztorm_discord-announcement_episode-7_v1.gif`

## post.md
```
# <Brand> · <Content> · <title> · v<N>

## Instagram            (or: YouTube / LinkedIn / Story / Discord / Ad)
<post copy>

<hashtags>

## TikTok               (Reel and Trial reels only)
## YouTube Shorts       (Reel and Trial reels only)

## Pinned comment       (Reel, YouTube: one line that continues the joke or asks the send-trigger question)
## Alt text             (Post, Carousel: one line per image)
## Cover                (the cover words, 3–5)
## Posting note         (one line: e.g. "Post as a trial reel; check results in 72 h")
```

## Post copy formula (Social)
1. Line 1: continues the hook's joke. It shows before "more", so keep it under 125 characters.
2. Lines 2–3: the payoff or the value.
3. Line 4: a question that makes people think of someone to tag, without asking them to tag ("Which friend is the 5 a.m. one?").
4. Line 5: call to action, only when the script type is Ad or the brand asked for one.
Never "link in bio" mid-story, never beg for shares. Use the brand's tone from the Brand Profile.

TikTok: shorter (1–2 lines + question). Shorts: a title-like first line + 1 line.

## Hashtags — the 1·1·3 rule
- 1 brand hashtag + 1 series hashtag (if the brand has one) + up to 3 niche or topic hashtags, from the Brand Profile and the topic. Maximum 5 on Instagram (platform limit, caption and comments combined).
- TikTok 3–5, YouTube 3 (in the description), LinkedIn 3.
- No generic tags (#viral, #love, #fyp). No hashtags on Story, Discord, Sales page video or ads.

## YouTube
- 3 title options (under 60 characters, the hook as a promise or a question).
- Description: 2 lines of summary, chapters (`00:00 Intro`… from the storyboard), 3 hashtags at the end.
- Thumbnail file.

## LinkedIn
Post text: hook line, 2–3 short paragraphs with one concrete lesson or number, a question to the reader, 3 hashtags.

## Sales page video
Headline (under 10 words), subheadline (one sentence), poster frame file. No hashtags.

## Ads
Primary text (2–3 lines, the hook first), headline (under 40 characters), description (one line), suggested button. No hashtags.

## Story
Per frame: on-screen text, the sticker (type, exact text, position), the link if any. No post copy, no hashtags.

## Discord
The message is written in Discord markdown (`discord.md`). The `#` in Discord is a heading, not a hashtag.
