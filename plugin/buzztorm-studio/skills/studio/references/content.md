# Content catalog

What each content is, its sizes, and what its delivery package contains. Options marked ✓ apply and appear on the review card; options not listed never appear for that content.

## Social

| Content | Size | Length | Files | Options |
|---|---|---|---|---|
| **Reel** | 9:16, 1080×1920 | 15–60 s | video, cover (1080×1920, key content in the centre 1080×1350), `post.md` with Instagram, TikTok and Shorts versions | Subtitles ✓ Post copy ✓ Hashtags ✓ |
| **Trial reels (hook test)** | 9:16 | 15–60 s | 3 videos (same body, different first 3 s), 3 covers, `post.md` with one post copy per hook, written for people who don't follow the brand yet | Subtitles ✓ Post copy ✓ Hashtags ✓ |
| **Post** (1 slide) | 4:5, 1080×1350 | — | image, `post.md` | Post copy ✓ Hashtags ✓ Alt text ✓ |
| **Carousel** | 4:5, 1080×1350 × 3–10 | — | slides `_01…_N`, `post.md` (alt text per slide) | Post copy ✓ Hashtags ✓ Alt text ✓ |
| **Story** | 9:16, 1080×1920 × 1–5 | 5–15 s per frame if animated | frames (PNG, or MP4 if animated), `post.md` with the sticker plan | none |

Rules:
- Reel and Trial reels: frame 1 is already the hook image. Hard cuts every 1.5–3 s. Loop the end into the start when possible.
- Trial reels are shown only to people who don't follow the account and stay off the grid until shared to everyone. Instagram limits who can use them (minimum follower count), so mention that once if the brand has never used them.
- Post and Carousel follow the Instagram layout in `library/docs/FORMATS.md` (Social post layout): same title plate and size on every slide, slide number, swipe cue, dialogue in big bands, 64 px safe margins. Slide 1 is the hook. A call-to-action slide is always added after the story slides: comment a keyword or join the brand's free community (Buzztorm: Buzztorm Academy).
- Story: reserve the top 250 px and bottom 340 px of each frame for the platform UI and the sticker. The sticker plan says which sticker (poll, quiz, question, link, countdown), its exact text and where it goes.

## YouTube & Web

| Content | Size | Length | Files | Options |
|---|---|---|---|---|
| **YouTube video** | 16:9, 1920×1080 | 1–8 min | video, thumbnail 1280×720, `post.md` with 3 title options, description with chapters, hashtags | Subtitles ✓ Post copy ✓ Hashtags ✓ (3) |
| **Sales page video** | 16:9 (or 9:16 for mobile pages) | 2–4 min | video, poster frame, `post.md` with headline and subheadline for the page | Subtitles ✓ |
| **LinkedIn video** | 16:9 or 4:5 | 30–90 s | video, cover, `post.md` with LinkedIn post text | Subtitles ✓ Post copy ✓ Hashtags ✓ (3) |
| **Presentation loop** | 16:9 | 5–15 s, seamless loop | MP4 loop + GIF | none |

Rules:
- YouTube chapters come from the storyboard: each scene's start time becomes a chapter (00:00 first, at least 3 chapters, each at least 10 s).
- YouTube thumbnail: character close-up on one side at 40 % of the width, 3–5 big words on the other, no small text.
- Sales page video follows the VSL structure (`scripts.md`, script type Sales pitch).

## Discord
See `discord.md`. Options: Mention ✓ (Announcement, Event), Alt text ✓ (Stickers: the sticker description).

## Option meanings
- **Subtitles**: burned-in captions on the video (`CAP=1` when rendering). Default from the Brand Profile.
- **Post copy**: the text to publish with the content (caption, description, post text).
- **Hashtags**: up to 5 on Instagram (hard platform limit, caption and comments combined), 3–5 on TikTok, 3 on YouTube and LinkedIn, none on Story, Discord, Sales page video or ads.
- **Alt text**: an image description for screen readers, one per image or slide.
- **Mention** (Discord): None ★ · A role · @everyone.

## Ads
Any Social or YouTube content can use the script type **Ad**. Ad delivery replaces post copy and hashtags with: primary text, headline, description, suggested button (Learn more, Sign up, Book now…). Subtitles are on by default for ads. The brand must be visible within 3 s.
